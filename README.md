# Stock Market Analysis Using Time-Series Forecasting

This project presents an end-to-end analysis of historical stock market data using data visualization, statistical exploration, and deep learning-based forecasting techniques. It focuses on understanding market trends and building predictive models with Long Short-Term Memory (LSTM) networks to estimate future stock prices from time-series data.

The repository includes notebooks for exploratory data analysis, stock market visualization, LSTM model training, and hyperparameter tuning. Using features such as Open, High, Low, Close, Volume, and Adjusted Close prices, the project demonstrates how machine learning can be applied to financial data for forecasting and pattern discovery.

## Key Highlights
- Exploratory data analysis of historical stock market data
- Visualization of price trends, moving averages, returns, and distributions
- LSTM-based deep learning model for time-series forecasting
- Hyperparameter tuning to improve model performance
- Practical workflow for financial data preprocessing and prediction
